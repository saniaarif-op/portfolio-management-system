# 3–5 Minute Demo Video Script

## 0:00–0:25 — Introduction
Introduce the Portfolio Management System and explain that it allows creators to manage professional information from a dashboard and publish it through a unique username URL.

## 0:25–1:10 — Creator Login
Show the login screen, sign in and open the dashboard.

## 1:10–2:00 — Profile Management
Show name, username, professional title, bio, location, profile image URL, skills and social links. Update a field and save it.

## 2:00–2:55 — Project Management
Add a project, technology tags, image URL and links. Edit a project and demonstrate delete/reordering.

## 2:55–3:40 — Public Portfolio
Open `/portfolio/username`. Show responsive profile, skills, project cards, live/GitHub links and contact section.

## 3:40–4:20 — API and Technical Decisions
Briefly show the backend routes, database schema and protected API requests. Mention JWT authentication, bcrypt password hashing, Zod validation, ownership checks, Helmet and rate limiting.

## 4:20–4:45 — Closing
Mention that the system fulfills the Week 03 requirements and is documented for local setup and deployment.
