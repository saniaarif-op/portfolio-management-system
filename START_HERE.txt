PORTFOLIA — ENCODERX WEEK 03
=============================

1. Open this whole folder in VS Code.

2. Backend:
   cd backend
   npm install
   copy .env.example .env
   npx prisma migrate dev --name init
   npm run seed
   npm run dev

3. Frontend:
   Open another VS Code terminal.
   cd frontend
   npm install
   copy .env.example .env
   npm run dev

4. Open the frontend URL shown by Vite.
